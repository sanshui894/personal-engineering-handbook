# Technical Glossary

**Status:** `MIGRATION_PENDING`

每个词条必须遵守 [Knowledge Provenance Standard](../governance/KNOWLEDGE_PROVENANCE_STANDARD.md)。项目内部缩写必须明确标记为 `PROJECT_SPECIFIC`；尚未验证的定义标记为 `UNVERIFIED`。
