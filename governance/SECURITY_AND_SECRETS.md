# Security and Secrets

## 禁止提交

无论仓库是否私有，禁止提交：

- `.env` 与真实环境变量文件；
- SSH 私钥；
- WireGuard 私钥；
- 含 `PrivateKey` 的可用配置；
- VPN 二维码；
- API Key；
- JWT、Cookie 和 Token；
- 密码；
- 数据库；
- 用户凭据；
- 原始供应商响应；
- 未脱敏日志；
- benchmark 原始敏感结果；
- 完整可用的客户端配置。

示例必须使用明显无效的占位符，且不能组合成可用凭据。发现疑似 Secret 时停止提交，先报告并按用户批准的方式处理；不得把删除文件等同于历史已安全清除。

## 私有仓库允许记录

以下信息可在确有维护价值时记录，但每条必须标记来源、最后核验日期、状态和敏感级别：

- 公网 IP；
- 内网 IP；
- 虚拟网段；
- 端口；
- 服务名称；
- 公钥用途或指纹，但不记录敏感密钥正文；
- 脱敏且不可直接使用的配置示例；
- 最后核验日期。

建议敏感级别：`PUBLIC`、`INTERNAL`、`PRIVATE-INFRASTRUCTURE`、`SECRET`。`SECRET` 只用于说明信息类别，Secret 正文本身不得进入仓库。
